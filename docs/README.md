# Documentação do AURA / Kiss-Flow OS

## Regra editorial

O arquivo Markdown é a fonte de verdade do manual:

1. consultar manual-execucao-10-semanas.md antes de qualquer alteração;
2. atualizar o Markdown primeiro;
3. revisar se a versão HTML continua coerente;
4. só então atualizar manual-execucao-10-semanas.html para refletir a mudança visual.

Arquivos principais:

- manual-execucao-10-semanas.md — manual canônico, leitura rápida e execução;
- manual-execucao-10-semanas.html — versão visual para impressão/PDF;
- plano-executivo.html — plano executivo e simulador ilustrativo;
- prototipo.html — demonstração frontend dos fluxos;
- base_conhecimento_rag.md — regras e guardrails da base de conhecimento.

## Critério de atualização

Toda mudança no manual deve indicar, quando aplicável:

- hipótese ou decisão alterada;
- etapa/gate afetado;
- métrica ou critério de aceitação;
- risco introduzido ou mitigado;
- impacto em custo, prazo ou escopo.

O Gate 0 continua sendo a decisão antes de mobile nativo, pagamentos e tráfego pago.
